# Freelance ต้องมีเอกสารอะไรบ้าง? คู่มือครบชุดก่อนรับงานแรก

หนึ่งในความกลัวของ Freelance มือใหม่คือเรื่องเอกสาร หลายคนถามว่า "ต้องทำอะไรบ้าง?" "มีแค่ใบเสร็จพอไหม?" หรือ "ถ้าไม่มีเอกสารจะเป็นไร?"

คำตอบตรงๆ คือ: Freelance ที่ไม่มีเอกสารมักเจอปัญหา — ลูกค้าโต้แย้งราคา จ่ายช้า หรือปฏิเสธงานที่ทำไปแล้ว เอกสารที่ถูกต้องคือระบบป้องกันตัวเองที่ดีที่สุด

บทความนี้จะพาคุณรู้จักเอกสารทั้ง 4 ประเภทที่ Freelance ทุกคนต้องรู้จัก พร้อมบอกว่าใช้ตอนไหน และทำไมถึงสำคัญ

---

## ภาพรวม: Flow เอกสารของ Freelance

ก่อนไปรู้จักแต่ละประเภท ให้เข้าใจภาพรวมก่อน:

```
[ได้งาน] → [ออกใบเสนอราคา]
              ↓ ลูกค้ายืนยัน
          [ทำงาน]
              ↓ งานเสร็จ
          [ออกใบแจ้งหนี้]
              ↓ ลูกค้าตรวจรับงาน
          [ออกใบตรวจรับงาน] ← (บางงาน)
              ↓ ลูกค้าโอนเงิน
          [ออกใบเสร็จรับเงิน]
              ↓
          [จบโปรเจกต์] ✓
```

ไม่ใช่ทุกงานที่ต้องมีครบทั้ง 4 แต่รู้จักทุกตัวไว้เพื่อใช้ได้ถูกสถานการณ์

---

## เอกสารที่ 1: ใบเสนอราคา (Quotation)

### ใช้เมื่อไหร่?

ก่อนรับงาน — ออกทุกครั้งที่มีการเสนอราคาให้ลูกค้า

### ทำหน้าที่อะไร?

แจ้งลูกค้าว่าคุณจะทำอะไร ในราคาเท่าไหร่ และมีเงื่อนไขอะไรบ้าง เมื่อลูกค้ายืนยัน นั่นคือการตกลงรับงาน

### รหัสเอกสาร: QO

ตัวอย่างเลขที่: `QO260500001`

### ข้อมูลสำคัญที่ต้องมี:

- ข้อมูลผู้เสนอและผู้รับ
- รายการงาน/บริการ พร้อมราคา
- ยอดรวมและภาษี (ถ้ามี)
- **วันหมดอายุของข้อเสนอ** — สำคัญมาก อย่าลืม
- เงื่อนไขการชำระเงิน

### ทำไมถึงสำคัญ?

- เป็น Reference สำหรับออกใบแจ้งหนี้ทีหลัง
- ป้องกันลูกค้า Request งานเพิ่มโดยไม่คิดเงิน (Scope Creep)
- แสดงความเป็นมืออาชีพ ทำให้ลูกค้ามั่นใจมากขึ้น

### เมื่อไหร่ที่ไม่ต้องออก?

งานเล็กมากๆ ที่ตกลงด้วยวาจาและราคาต่ำ อาจข้ามได้ แต่ไม่แนะนำ

---

## เอกสารที่ 2: ใบแจ้งหนี้ (Invoice)

### ใช้เมื่อไหร่?

หลังส่งงาน — นี่คือบิลเรียกเก็บเงิน

### ทำหน้าที่อะไร?

บอกลูกค้าว่าต้องจ่ายเงินเท่าไหร่ ภายในวันไหน และโอนมาที่บัญชีไหน

### รหัสเอกสาร: IV

ตัวอย่างเลขที่: `IV260500001`

### ข้อมูลสำคัญที่ต้องมี:

- ข้อมูลผู้ออกและผู้รับ
- รายการงานและราคา (อ้างอิงจาก Quotation ได้)
- ยอดรวม ภาษี ยอดสุทธิ
- **วันครบกำหนดชำระ (Due Date)** — สำคัญที่สุด
- ข้อมูลบัญชีธนาคารสำหรับโอนเงิน

### ทำไมถึงสำคัญ?

- มี Due Date = ลูกค้ารู้ว่าต้องจ่ายวันไหน
- มีบัญชีธนาคาร = ลูกค้าโอนได้ทันทีไม่ต้องถาม
- มีเลขที่ Invoice = ติดตามสถานะการชำระได้

### ความแตกต่างจากใบเสนอราคา:

ใบเสนอราคา = ก่อนจ่าย, ยังไม่ได้ทำงาน
ใบแจ้งหนี้ = หลังทำงาน, เรียกเก็บเงิน

---

## เอกสารที่ 3: ใบตรวจรับงาน (Acceptance Certificate)

### ใช้เมื่อไหร่?

หลังส่งงาน + ลูกค้าตรวจและยอมรับงานแล้ว — บางงานออกพร้อมกับหรือก่อนใบแจ้งหนี้

### ทำหน้าที่อะไร?

เป็นหลักฐานว่าลูกค้าตรวจงานแล้วและยอมรับว่างานเสร็จตามที่ตกลงไว้ ใช้ในการยืนยันว่าสามารถเรียกเก็บเงินได้

### รหัสเอกสาร: AC

ตัวอย่างเลขที่: `AC260500001`

### ข้อมูลสำคัญที่ต้องมี:

- ข้อมูลผู้ส่งมอบและผู้รับมอบ
- รายการงานที่ส่งมอบ
- วันที่ส่งมอบ
- ช่องลายเซ็นสำหรับทั้งสองฝ่าย (ชื่อ + วันที่)
- อ้างอิงเลขที่ Invoice หรือ Quotation

### ทำไมถึงสำคัญ?

นี่คือเอกสารที่ Freelance มักไม่ใช้ แต่จำเป็นมากในงานบางประเภท โดยเฉพาะ:

**งาน IT / Software Development:**
บริษัทลูกค้ามักต้องการเอกสารนี้เพื่อประกอบการขอเบิกเงินในระบบ Finance ภายใน ถ้าไม่มี กว่าเงินจะออกอาจใช้เวลา 1–2 เดือนเพิ่มเติม

**งาน Project-Based:**
เมื่อมีการโต้แย้งในภายหลังว่า "งานยังไม่เสร็จ" หรือ "ไม่ได้ส่งมอบ" — ใบตรวจรับงานที่ลูกค้าเซ็นชื่อเป็นหลักฐานชัดเจนที่สุด

**งาน Milestone-Based:**
ถ้าโปรเจกต์มีหลาย Phase ออกใบตรวจรับงานทีละ Phase เพื่อยืนยันก่อนทำต่อ

### สถานการณ์ที่อาจข้ามได้:

งานเล็ก งานบุคคลที่ไม่ใช่บริษัท หรืองานที่เน้นความรวดเร็ว อาจใช้แค่ใบแจ้งหนี้โดยไม่ต้องมีใบตรวจรับงาน

---

## เอกสารที่ 4: ใบเสร็จรับเงิน (Receipt)

### ใช้เมื่อไหร่?

หลังได้รับเงินแล้ว — นี่คือการยืนยันว่าการชำระเงินเสร็จสมบูรณ์

### ทำหน้าที่อะไร?

ยืนยันกับลูกค้าว่าคุณได้รับเงินแล้ว ปิดวงจรการทำธุรกรรม

### รหัสเอกสาร: RC

ตัวอย่างเลขที่: `RC260500001`

### ข้อมูลสำคัญที่ต้องมี:

- ข้อมูลผู้รับเงินและผู้จ่าย
- รายการที่ชำระ
- ยอดที่รับ
- วันที่รับชำระ
- วิธีการชำระ (โอนธนาคาร / เงินสด / เช็ค)
- ชื่อผู้รับเงิน

### ทำไมถึงสำคัญ?

- ลูกค้าใช้เป็นหลักฐานค่าใช้จ่ายในระบบบัญชีภายใน
- ป้องกันการร้องเรียนในภายหลังว่าจ่ายเงินไปแล้วแต่ไม่ได้รับการยืนยัน
- ช่วยให้คุณ track ว่าเงินเข้าครบหรือยัง

### ความแตกต่างสำคัญจากใบแจ้งหนี้:

ใบแจ้งหนี้ = ขอเงิน (ยังไม่ได้รับ)
ใบเสร็จรับเงิน = ยืนยันว่าได้รับเงินแล้ว

## Timeline: เอกสารแต่ละตัวใช้ตอนไหน

### โปรเจกต์แบบ Fixed Price (ทั่วไปที่สุด)

```
วันที่ 1:   ตกลงรับงาน → ออก ใบเสนอราคา (QO)
วันที่ 2:   ลูกค้า Approve → เริ่มทำงาน
             (บางงาน: รับมัดจำก่อน → ออก ใบเสร็จ RC สำหรับมัดจำ)
วันที่ 14:  ส่งงาน → ออก ใบแจ้งหนี้ (IV) + ใบตรวจรับงาน (AC)
วันที่ 21:  ลูกค้าโอนเงิน → ออก ใบเสร็จรับเงิน (RC)
```

### โปรเจกต์แบบ Milestone (งานใหญ่)

```
Phase 1:
  เริ่มงาน → ออก QO รวม
  → ส่ง Phase 1 → ออก IV + AC สำหรับ Phase 1
  → รับเงิน → ออก RC

Phase 2:
  → ส่ง Phase 2 → ออก IV + AC สำหรับ Phase 2
  → รับเงิน → ออก RC
```

### งาน Retainer รายเดือน

```
ต้นเดือน: ออก IV สำหรับเดือนนั้น
ทุกวันที่ X: รับเงิน → ออก RC
(ไม่ต้องออก QO และ AC ทุกเดือน — ทำครั้งแรกรอบเดียวพอ)
```

## 5 เหตุผลที่ Freelance ต้องมีระบบเอกสารที่ดี

### 1. ป้องกันปัญหาการไม่จ่ายเงิน

ลูกค้าที่รู้ว่ามีเอกสารและมี Due Date ชัดเจน มักจ่ายตรงเวลามากกว่า งานที่ตกลงด้วยปากเปล่าเสี่ยงเรื่องนี้มากที่สุด

### 2. ป้องกัน Scope Creep

ถ้ารายการงานอยู่ในใบเสนอราคาชัดเจน ลูกค้าของานนอก Scope ได้ยากขึ้น คุณมีสิทธิ์คิดเงินเพิ่มได้โดยไม่รู้สึกผิด

### 3. ใช้เป็นหลักฐานถ้าเกิดข้อพิพาท

กรณีที่ต้องฟ้องร้อง (หวังว่าจะไม่เกิด) เอกสารที่ครบถ้วนคือหลักฐานที่ดีที่สุดที่มีสิทธิ์บนเท็กซ์คุณ

### 4. ช่วยในการยื่นภาษีประจำปี

Freelance ที่มีรายได้ต้องยื่นภาษีเงินได้บุคคลธรรมดา ใบแจ้งหนี้และใบเสร็จช่วยให้คุณรู้รายได้จริงของปี และมีหลักฐานประกอบ

### 5. แสดงความเป็นมืออาชีพ

ลูกค้าที่ดีให้ความสำคัญกับผู้ให้บริการที่มีระบบ มีเอกสารครบ บริหารงานชัดเจน มักได้งานใหม่ต่อเนื่องมากกว่า

## คำถามที่พบบ่อย

**ถ้าเป็น Freelance รายเล็ก ไม่จดทะเบียนบริษัท ต้องมีเอกสารไหม?**
ต้องมี เอกสารทั้ง 4 ประเภทออกได้โดยไม่ต้องจดทะเบียนบริษัท ใช้ชื่อ-นามสกุลส่วนตัวก็ได้

**ถ้าลูกค้าเป็นคนรู้จักหรือเพื่อน ต้องมีเอกสารไหม?**
ควรมี โดยเฉพาะถ้าจำนวนเงินไม่ใช่น้อยๆ ความสัมพันธ์ส่วนตัวกับความสัมพันธ์ทางธุรกิจควรแยกกันชัดเจน

**ต้องพิมพ์เอกสารออกมาหรือแค่ PDF ก็พอ?**
PDF ก็พอในกรณีส่วนใหญ่ ส่งทาง Email หรือ LINE ได้เลย ยกเว้นบางองค์กรที่ต้องการกระดาษพร้อมลายเซ็น

**ถ้าลูกค้าต่างประเทศ ต้องทำเป็นภาษาอังกฤษไหม?**
แนะนำให้ทำเป็นภาษาอังกฤษ หรืออย่างน้อยมีทั้งไทยและอังกฤษ ทำให้ลูกค้าเข้าใจและอนุมัติได้เร็วกว่า

---

## เริ่มต้นใช้งานเอกสารวันนี้ได้เลย

ถ้าคุณยังไม่มีระบบสร้างเอกสาร และกำลังมองหาเครื่องมือที่:

- ✓ ฟรี ไม่มีค่ารายเดือน
- ✓ ไม่ต้องสมัครสมาชิก
- ✓ รองรับภาษาไทยและอังกฤษ
- ✓ ส่งออก PDF ได้ทันที
- ✓ มีครบทั้ง 4 ประเภทเอกสาร
